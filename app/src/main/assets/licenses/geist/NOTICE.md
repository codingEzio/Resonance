See provenance.json for exact sources, sizes, Git blobs and SHA-256.

Geist serves normal Latin text; Geist Mono serves controls and technical values.
CJK uses platform fallback; these assets do not provide Chinese glyphs.
Nothing OS 5.0 officially adopts Geist: https://nothing.community/d/61774.
The optional Doto display face is a separate OFL approximation, not Nothing Ndot.
No NType82, Ndot or Lettera Mono proprietary font is bundled.
